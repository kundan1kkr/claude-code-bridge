Pro-Tip: "Plan Mode" vs "Auto Mode" in Claude Code

If Claude Code prints plan mode on, it will NOT execute tools, read files, or write code. Press Shift + Tab in your terminal to toggle back to normal/auto execution mode.

Recommended for Autonomous Agents

1. Autonomous Agent Mode

Runs Claude Code with auto-approvals enabled so it executes bash commands, file edits, and tool actions continuously without stopping to ask permission.

./run_claude.sh --dangerously-skip-permissions
Runs via LiteLLM Proxy on http://localhost:4000 with your active primary model.

2. Interactive Safe Mode

Prompts you to approve each shell command and file write before executing. Ideal for delicate or exploratory tasks.

./run_claude.sh
Standard mode with manual approval gates.

3. Claude Desktop (Mac App)

Connect the official Claude Desktop app on macOS to route through this bridge:

File: ~/Library/Application Support/Claude/claude_desktop_config.json 
{
  "anthropic_base_url": "http://localhost:4000",
  "anthropic_api_key": "sk-litellm-proxy"
}

4. Manual Shell Environment

If you want to run claude directly in any shell window:

export ANTHROPIC_BASE_URL="http://localhost:4000" export ANTHROPIC_API_KEY="sk-litellm-proxy" claude
